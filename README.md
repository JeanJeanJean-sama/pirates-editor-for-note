# Pirates' Editor for note（Pen） v0.7.1 — β版

自分のnoteの数値（インプレッション・PV・スキ・コメントなど）を毎日記録・分析する道具です。**note公式のサービスではありません**（note株式会社とは関係ありません）。

noteのアクセス数値を毎日自動で記録し、推移を見える化するChrome拡張機能です（スマホ・Chrome以外のブラウザ向けのWeb版もあります）。取得するのは**自分のアカウントのデータだけ**です。
未返信のコメントや、自分が他の人の記事に書いたコメントも記録します。記録はブラウザの中にだけあり、外には送りません。

> noteの仕様が変わると動かなくなることがあります。

## ストア公開記念の特典：過去の記録を埋める（1.0.0 まで）

Chromeウェブストアでの公開を記念して、**拡張機能版の全員**に、期間限定（1.0.0 まで）で「過去の記録を埋める」を使えるようにしました。「設定」の「過去の記録を埋める」で「始める」を押すと、noteから、最初の記事を公開した日から昨日までの「その日の終わり時点の累計」を1日ずつ取り、記録のない日を埋め、記録のある日の数字を note の正しい値に直します。

- 時間の目安は、記事200本・1年分で約15分です（noteへは1.2秒以上あけて、自分の数字の読み取りだけ）。途中で閉じても続きから始まります。
- 全部取れたら照合し（PV・スキ・コメント・売上が減る日が無いか、日ごとの増えた数と合うか）、「埋める」を押したときに初めて記録を書き換えます。
- フォロワー数の昔の推移は note から取れないので、新しく作った日のフォロワー数は空のままです。
- β版から移る人は、**引っ越し用ファイルの復元を先に**、そのあとで埋めてください。
- Web版にはありません（GitHub Pages は商用に使えず、将来の有料機能のため）。1.0.0 でボタンは無くなりますが、埋めた記録はそのまま残ります。

## β版から移る人へ

以前の名前のβ版（0.6.3 まで）を使っていた人は、次の3つの手順で、記録・設定・称号・β版からの特典を引き継げます。

1. β版を **0.6.3** に上げる（0.6.3 より前の版には、引っ越し用ファイルを作る機能がありません）
2. β版の「設定」→「正規版への引っ越し」で、**⬇ 正規版（Pirates' Editor for note）への引っ越し用ファイル**（`pen-move-YYYYMMDD.json`）をダウンロードする
3. Pen を[Chromeウェブストア](https://chromewebstore.google.com/detail/oknmpkaeflacodfgeiigipboaiojpmne)から入れて、「設定」の「⬆ バックアップファイルから復元」で、2. のファイルを読み込む
4. （拡張機能版）そのあとで「過去の記録を埋める」を押す

- β版の以前のバックアップ（0.6.3 の引っ越し用ファイルではないもの）は、Pen では読み込めません。β版で一度復元してから、引っ越し用ファイルを作ってください。
- Pen の記録の置き場所は、β版とは別です（Pen は空の状態から始まります）。
- Web版は、新しいWeb版を開いて、ブックマークレット「Penで記録」を登録し直してください。

## インストール（GitHub から直接入れる場合）

1. ZIPを展開し、中の `pirates-editor-for-note` フォルダを消さない場所に保存します。
2. Chromeで `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押して、このフォルダを選びます。
4. noteにログインした状態で `https://note.com/` を開きます。数十秒後に最初の記録が保存されます。
5. ツールバーのアイコンを押すと、ダッシュボードが開きます。

## 仕組みと安全性

- noteとの通信は、**noteのページ内（content script）でだけ**行います。
- 認証には、noteがブラウザに用意するCookie `note_gql_auth_token` を使います。拡張機能が自分で発行したり、保存したり、外部に送ったりすることはありません。
- noteへのリクエストは**1秒以上の間隔**をあけて送ります。
- 取得するタイミング
  - 全期間の記録：1日1回（「2014/4/1〜その日」の期間を指定した累計。note の「全期間」の集計が崩れることがあるため）
  - 過去の記録を埋める（押したときだけ）：最初の記事の日から昨日までの1日ごとに、記事数÷100回。1.2秒以上の間隔。ログインの印を新しくするため、3分ごとに note のトップページを見えない枠で読み込む
  - 前の日の記録の確定：記録のたびに、まだ確定していない過去の記録の日を最大30日分（1日あたり 記事数÷100回の問い合わせ）。noteの集計が次の日に進むまで待つ
  - 通知の1ページ目：noteのページを開いたとき・移ったとき（開いたままのときも）、前に読んでから5分以上たっていれば1回（間隔は設定で 5分・15分・30分・1時間）。自分の記事へのコメントや自分のコメントへの返信が来ていたら、その記事のコメントだけを確かめます
  - 未返信コメントの確認：6時間ごと。記事一覧を読み直して、コメント数が変わった記事だけを確認します（読み直した数字は毎日の記録には使いません）
  - 通知の確認（全体）：12時間ごと
  - コメントに気づけるのは note を開いたときです（noteを開いていないときは何もしません）
- 保存先は、このブラウザの拡張機能用の保存領域（IndexedDB）だけです。外部のサーバーには何も送りません。
- 記録の前に、ログイン中のアカウントが「記録するアカウント」と同じか確かめます（`/api/v2/current_user`）。noteのログインの印が前と同じなら24時間は前の結果を使うので、問い合わせは1日に数回までです。ログインの印そのものは保存せず、見分けるための指紋（SHA-256）だけをブラウザ内に記録します。
- 「設定」の「noteから記録する」で、通信を伴う機能（自動の記録・コメントの確認・自分のコメントの記録・本文の取り込み・称号の確認）をそれぞれOFFにでき、OFFにした機能の通信は行いません。
- 使う権限は `unlimitedStorage`（ブラウザ内の保存領域の容量制限をなくす）と `https://note.com/*` の2つだけです。

## noteの利用規約について・運営の皆さまへ

Pen は、note の書き手が **自分自身のデータ** をふり返るために作った、個人による道具です。note公式のサービスではなく（note株式会社とは関係がなく）、公式の許可を得たものでもありません。note に迷惑をかけないよう、次のことを守っています。

- 取得するのは、ログインしている本人のデータと、誰でも見られる公開情報だけです。他人の非公開データは取得しません。
- ログインが必要な画面の制限を回避したり、有料記事を本来の方法以外で読んだりすることはしません。
- note へのリクエストは1秒以上の間隔をあけ、1日1回を基本にしています。
- 取得したデータは利用者のブラウザ内にだけ保存し、開発者を含む外部には送りません。
- 広告は表示せず、取得したデータを販売・分析・第三者提供に使うことはありません。

利用者の皆さまも、note の[利用規約](https://note.com/terms)を守ってお使いください。

**note株式会社の皆さまへ**：本ツールについて、仕様の変更・機能の停止・公開の停止などのご要望があれば、速やかに対応します。[Issues](https://github.com/jeanjeanjean-sama/pirates-editor-for-note/issues) またはメール（remmusnaej@gmail.com）でご連絡ください。

| コメントのやり取りの返信 | `GET /api/v3/notes/{key}/note_comments?parent_key={親コメント}&order=oldest`（返信への返信も含めて古い順。自分の記事と、自分がコメントした公開の記事だけ） |
| 通知 | `GET /api/v3/notices`（ふだんは1ページ目だけ。12時間ごとに最大25ページ、約300件。種類 `note_comment`・`note_comment_reply`・`note_comment_like` を使う。既読にはしない） |
| 記事の本文 | `GET /api/v3/notes/{key}`（noteのページ内・ログイン状態で取得） |
| フォロー特典の確認 | `GET /api/v2/creators/jeanjeanjean`（`isFollowing`）、`GET /api/v2/creators/noah_woaks`（`isFollowing`。魔王軍）、`GET /api/v2/creators/jeanjeanjean/contents`（`isLiked`）、彼の記事の `note_comments` |

## 既知の制限

- 記録はアカウントごとに分けて持っていません。記録するアカウントを変えると、今までの記録と同じ場所に入ります（アカウントごとに分けて見る機能は今後の予定）。

- 無料版は「全期間の累計」を毎日記録し、その差から日ごとの増えた数を出します。記録しなかった日があると、その区間は数日分がまとめて1点になります（拡張機能版は、1.0.0 までの特典「過去の記録を埋める」で埋められます）。
- 自分のコメントのうち、拡張機能を入れる前に書いたものは、その記事を開き直すか、返信・スキの通知が届いたときに追加されます。
- 「今すぐ取得」でnoteのタブを裏で開いたときは、Chromeの省電力機能で処理が遅くなることがあります。
